# Expense Ratio (TER)

**What it is:** The annual fee deducted from NAV daily — already netted into every return you see. "Returns are a hope; expenses are a promise." Screenshots show "Base Expense Ratio" (0.53–0.79%) and "Interim Net Expense Ratio" (0.4–0.8%) — different slices of the same idea.

**How to read it:** Lower is better, compared only within category and plan type. Expense is charged on assets, not returns: a 1% TER on a 12%-return fund eats ~1/12th (≈8%) of your gross return yearly, before any skill question is asked. It's one of the few metrics with real predictive power for future relative returns — cheap funds start every year ahead.

**Thresholds / zones:** Direct, all-in: index 0.05–0.25%; active equity 0.4–1.0% (handbook's five funds: 0.53–0.79%); debt 0.2–0.6%; liquid <0.25%. 1.5%+ active equity "needs an extraordinary excuse." [2026] SEBI cut TER caps ~15 bps from Apr 2026.

**The trap:** Focusing on returns while ignoring that expense is the one certain, compounding number in the decision.

**Strong answer mentions:**
- Already netted into displayed returns; certain, unlike returns
- Compare only within category and plan type
- One of few metrics with real predictive power
- Rough bands: index 0.05–0.25%, active equity 0.4–1.0%, debt 0.2–0.6%
- A 1% drag compounds to large wealth differences over decades (§1.3)
