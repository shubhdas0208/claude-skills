# Manager Tenure

**What it is:** How long the current manager has actually run the fund — found on the fund page under "Fund Manager since." Distinct from fund age (time since scheme launch).

**How to read it:** A fund's displayed track record (returns, ratios, ratings) reflects whoever ran the money over that period — not the fund's name or brand. As the glossary puts it: "the track record belongs to the tenure, not the fund name." A 13-year-old fund whose manager arrived 18 months ago has 13 years of *brand* history but only 18 months of *relevant* history for judging that manager's actual skill.

**Thresholds / zones:** No numeric tenure threshold given — only the illustrative 13-year fund / 18-month manager contrast.

**The trap:** Assuming a fund's long-run stats (5-yr, 7-yr, since-launch CAGR, star ratings) all reflect the current manager's skill, when most of that history may belong to a manager who has since left.

**Strong answer mentions:**
- Fund age and manager tenure are different numbers, checked separately
- Track record belongs to the tenure, not the fund's name/brand
- Find via "Fund Manager since" on the fund page
- Long history + short current-manager tenure means most stats aren't this manager's evidence
- A manager exit is itself a monitoring trigger, not just a purchase-time check
