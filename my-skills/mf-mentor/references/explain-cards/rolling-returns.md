# Rolling Returns

**What it is:** Compute the 3-yr (or 5-yr) CAGR for *every possible start date* over a long stretch, then look at the distribution — the fix for point-to-point bias in a trailing number. It answers: "If I invested on a random day and held 3/5 years, what range of outcomes would I get?"

**How to read it:** Three things matter — average rolling return vs benchmark/category (the honest skill measure); minimum rolling return, the worst experience anyone had (worst 5-yr of +4% differs greatly from worst of −2%); and % of windows beating the benchmark, a consistency measure (beating it in 80% of rolling 3-yr windows demonstrates something real; one great year lifting trailing numbers does not).

**Thresholds / zones:** None as general rules — the +4%/−2% and 80% figures are illustrative, not stated cutoffs.

**The trap:** Relying only on trailing returns (a single window ending today) and mistaking a fund's luck of start/end dates for actual skill.

**Strong answer mentions:**
- Computes return for every possible start date, not one window
- Fixes point-to-point / end-date bias in trailing returns
- Average rolling return vs benchmark/category = honest skill measure
- Minimum rolling return shows the worst real experience possible
- Rule: "trailing returns to notice a fund; rolling returns to judge it"
