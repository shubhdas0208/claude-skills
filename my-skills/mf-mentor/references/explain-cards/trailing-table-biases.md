# Trailing-Returns Table Biases

**What it is:** Three structural biases baked into every trailing-returns table, regardless of fund: end-date bias, recency-weighted psychology, and survivorship.

**How to read it:** **End-date bias** — all windows end *today*. After a small-cap boom, every small-cap fund looks brilliant at every horizon at once; after a crash, the same skilled managers all look bad — you're viewing the market's mood through the fund's window. **Recency-weighted psychology** — the brain treats 6-month returns as "what this fund does." Apps exploit this ("Highest Return MFs"); money flows into what just rose, buying high, structurally. **Survivorship** — bad funds get merged or closed, so category averages quietly improve; the funds you see today are the survivors.

**Thresholds / zones:** None given.

**The trap:** Reading a trailing-returns table as an objective, apples-to-apples measure of fund quality, when all three biases distort it the same direction — flattering whatever just did well and whatever survived.

**Strong answer mentions:**
- End-date bias: every window anchors to today, so recent mood shows at every horizon at once
- Recency-weighted psychology: recent returns get overweighted, and apps exploit this for "buy high" behavior
- Survivorship: closed/merged bad funds vanish, quietly flattering category averages
- All three biases point the same direction — flattering current winners
