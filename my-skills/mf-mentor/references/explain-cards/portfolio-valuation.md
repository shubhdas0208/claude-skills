# Portfolio Valuation (P/E vs Benchmark)

**What it is:** The portfolio's weighted price-to-earnings (P/E) or price-to-book (P/B) compared to its benchmark index's.

**How to read it:** This reveals the fund's *style temperature*. A portfolio P/E well above the benchmark = growth/momentum tilt (pays up for growth). Well below = value tilt. This context lets you correctly judge returns: a value-tilted fund lagging in a momentum market is doing its job as designed; a growth-tilted fund lagging in a momentum market is genuinely failing at what it's supposed to be good at.

**Thresholds / zones:** No numeric P/E or percentage threshold given — only the directional read (well above = growth tilt, well below = value tilt).

**The trap:** Judging any fund's underperformance the same way regardless of style — without checking valuation vs benchmark, you can't tell if a lagging fund is behaving as its style should, or genuinely failing.

**Strong answer mentions:**
- Portfolio P/E vs benchmark P/E reveals the fund's style tilt (growth vs value)
- Well above benchmark = growth/momentum tilt; well below = value tilt
- Contextualizes returns — a value fund lagging in a momentum market is "doing its job"
- A growth-tilted fund lagging in a momentum market is a real underperformance
- Connects to judging style funds across a full cycle, not short windows
