# Portfolio Turnover

**What it is:** The % of the portfolio replaced in a year (100% = the whole book turned once). Handbook spread: HDFC Flexi 9.21%, PPFAS 17.48%, SBI Contra 10%, SBI L&M 32%, ICICI Value 79%.

**How to read it:** Turnover reveals the strategy's metabolism, read *with* the fund's style, not on an absolute scale. Single-digit/teens % = buy-and-hold conviction (HDFC holds stocks ~10 years on average at 9%). 50–100% = active rotation — for ICICI Value arguably inherent to style (buy cheap → re-rates → sell → recycle). 150%+ in a plain fund = momentum-chasing or indecision. Every trade costs brokerage + impact atop the TER, and realizes gains early — high turnover must clear a higher skill bar to break even.

**Thresholds / zones:** Single-digit/teens % = conviction. 50–100% = active rotation (style-consistent). 150%+ in a plain fund = flag.

**The trap:** Reading turnover on an absolute scale instead of against the mandate — a flag only when it contradicts style or spikes vs. its own history.

**Strong answer mentions:**
- Turnover = % replaced yearly; read against stated style
- HDFC Flexi 9% (conviction) vs ICICI Value 79% (style-consistent rotation)
- 150%+ in a plain fund flags, doesn't disqualify
- Every trade adds silent costs atop TER, realizes gains early
- A spike vs. own history matters more than absolute level
