# Benchmarks and TRI

**What it is:** Every fund declares a benchmark index (e.g., Nifty 500 TRI for flexi-caps, Nifty Smallcap 250 TRI for small-caps). Always use the **TRI (Total Return Index, dividends included)** version — a non-TRI comparison flatters the fund by ~1–1.5%/yr.

**How to read it:** Returns are meaningless without a "compared to what." The real test is three-way, same window: fund vs benchmark vs category average. Fund 14%, benchmark 16% → manager destroyed value, an index fund was better. Fund 14%, benchmark 11%, category 12% → genuine outperformance vs both — check if it came with proportionate risk. Whole category beat the benchmark → common in small/mid-cap; segment inefficiency, not universal genius.

**Thresholds / zones:** A non-TRI comparison flatters a fund's apparent outperformance by roughly **1–1.5%/yr**.

**The trap:** Comparing a fund's return to a plain (non-TRI) index price return, silently inflating the fund's apparent skill by excluding the dividends the index also earned.

**Strong answer mentions:**
- Always compare against TRI, not the plain price index
- Non-TRI comparison flatters the fund by ~1–1.5%/yr
- The real test is three-way: fund vs benchmark vs category, same window
- Beating the benchmark should prompt checking for proportionate risk
- A whole category beating its benchmark usually means segment inefficiency, not universal skill
