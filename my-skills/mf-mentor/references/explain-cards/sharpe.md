# Sharpe Ratio

**What it is:** Sharpe = (Fund return − Risk-free rate) ÷ Standard deviation — excess return per unit of *total* volatility. Worked example: mean 14.22, SD 9.93, risk-free ~5.8–6% → (14.22−5.8)/9.93 ≈ 0.85.

**How to read it:** Compare only within category and same window — 3Y/5Y deserves more weight than a noisy 1Yr figure. Dashes at 3Y/5Y mean the fund is too young to compute — itself useful (unproven). SD punishes upside and downside equally, so explosive up-months get penalized — the trap Sortino fixes. Two funds can land on near-identical Sharpe via opposite personalities — higher return with higher SD vs lower return with much lower SD; Sharpe says both were similarly efficient, and which you prefer is stomach and goals, not "better."

**Thresholds / zones:** Sharpe 1.0 = very good for equity over a 3-yr window; 0.7–0.9 = solid; below ~0.4 = wobble without pay; negative = lost to a savings account (often a bad period, not a bad fund). §5.7 bands: weak <0.4, acceptable 0.4–0.8, strong >0.8–1.0.

**The trap:** Comparing Sharpe across categories or windows, or forgetting it penalizes upside volatility the same as downside.

**Strong answer mentions:**
- States the formula: excess return per unit of total volatility
- Applies the comparison rule: same category, same window, favor 3Y/5Y
- Names the symmetric-penalty trap (punishes good volatility too)
- Places a value into weak/acceptable/strong using §5.7 bands
- Reads similar Sharpe with different mean/SD as "similarly efficient, different personality"
