# 3-Year and 5-Year Trailing Returns

**What it is:** Both annualized (CAGR, per §3.1). 2/3-Year is "roughly half a cycle"; 5-Year "usually spans some stress." 3-year is also the standard window the handbook's risk ratios use.

**How to read it:** 2/3-Year — legit: first real skill signal, *if* compared within category; illegit: treating it as destiny, since a single bull run can dominate. 5-Year — legit: primary selection window for equity funds; illegit: ignoring that all 5-year windows ending today share the same recent boom/bust (end-date bias) — every window anchors to today regardless of fund.

**Thresholds / zones:** None given — compare against category peers and the category average, not a fixed number.

**The trap:** Reading a tightly clustered set of 3-yr numbers across funds as differentiation, when the handbook's example shows a cluster (14–17% at 3-yr) mostly reflects what "the category and market delivered" — fund choice mattered less than an app's ranking implies.

**Strong answer mentions:**
- Both are CAGR, not absolute return
- 3-yr is a first real skill signal only within category
- 5-yr is the primary selection window for equity funds
- All windows share end-date bias — anchored to today
- A single bull run can drive a tight cluster of results, not skill
