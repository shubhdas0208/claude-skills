# Ratio Combinations — The Interpretation Matrix

**What it is:** What combinations of *changes* across return, SD, Sharpe, beta, and alpha imply about a fund — read against its own history or against peers, not any single ratio in isolation.

**How to read it:** Never judge one ratio alone; read the *pattern* across return, risk, and the ratio connecting them. The table below is the handbook's matrix, reproduced in full.

**Thresholds / zones:** None beyond the matrix itself — this is a pattern-reading tool, not a scored threshold.

**The trap:** Reading a single ratio move in isolation instead of the combination — e.g., celebrating a rising beta without checking whether it's consistent with the fund's mandate, or treating a falling alpha as fund-specific failure when the whole category collapsed.

**Interpretation matrix (§5.6):**

| Observation | Most likely story | Your move |
| --- | --- | --- |
| Return ↑, SD flat, Sharpe ↑ | Efficient improvement — the good kind | Confirm with rolling returns; investigate what changed |
| Return ↑, SD ↑ faster, Sharpe ↓ | Bought returns with extra risk (down-cap drift, concentration) | Check portfolio for style drift |
| Return flat, SD ↓, Sharpe ↑ | De-risking without sacrificing return (skill, or lucky calm) | Fine; verify it's not closet-indexing (alpha → 0, R² → 95+) |
| Beta ↑ over successive periods | Manager getting aggressive / cash deployed | OK if consistent with mandate; flag if a "conservative" fund |
| Alpha ↓ toward 0 as AUM balloons | The classic size-kills-alpha decay | Consider whether the fund's edge still exists at this size |
| Sharpe great, Sortino barely higher | Volatility is symmetric — falls as hard as it rises | Prefer the peer with fatter Sortino gap if returns are similar |
| High return, high Sharpe, tiny fund age (dashes at 3Y/5Y) | Unproven — one regime of data | Wait, or size tiny; "no data" is data |
| Whole category's Sharpe collapses | Market regime, not 40 managers failing at once | Judge funds by relative position, or wait out the phase |
