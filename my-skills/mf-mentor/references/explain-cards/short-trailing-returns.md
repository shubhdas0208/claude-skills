# Short Trailing Returns (1D / 1W / 1M / 3M / 6M / YTD)

**What it is:** "Trailing" = measured backward from today. Per §3.1, periods under 1 year are shown **absolute**, not annualized. 1D = yesterday's NAV move; 1W/1M = recent market mood; 3M/6M = current market phase and style tailwinds; YTD = Jan 1 to today.

**How to read it:** 1D — legit: liveness check; illegit: any decision. 1W/1M — legit: noticing events (crash, rally, sector move); illegit: judging fund quality (~100% noise, 0% skill). 3M/6M — legit: spotting which styles favor (value vs growth, small vs large); illegit: extrapolating ("15% in 6 months → 30%/yr!"). YTD — legit: same-window calendar comparison; illegit: anything else, since it's an arbitrary start date.

**Thresholds / zones:** None given.

**The trap:** Sorting by short-period returns for "the best fund" — exactly what "Highest Return MFs" buttons do: sort by trailing return = buy whatever peaked recently = systematically buy high.

**Strong answer mentions:**
- Absolute (non-annualized), not CAGR, under 1 year
- Each period has a legit (context) use and illegit (decision) use
- 1D/1W/1M is near-total noise for fund-quality judgments
- 3M/6M shows style tailwinds, not a run rate to extrapolate
- "Highest Return" sorting = structurally buying high
