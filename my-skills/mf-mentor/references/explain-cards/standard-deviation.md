# Standard Deviation — The Width of the Ride

**What it is:** How far annual returns typically stray from their own average. Mean 14%, SD 10 → returns typically land between +4% and +24% (±1 SD ≈ two-thirds of outcomes if bell-curved; real markets have fatter tails — intuition, not law). Mean 14, SD 25 → range −11% to +39%: same average, very different ride.

**How to read it:** Compare only within category, against the category average. High SD isn't "bad" — *unpaid* SD is; the question is whether mean compensates it (what Sharpe computes). Low SD within an aggressive category is information — a manager damping volatility deliberately (cash, foreign stocks, value discipline). Rising SD over time (1Y vs 3Y) means the fund is getting wilder — concentration, down-cap drift, stormier markets; falling SD means calmer seas or de-risking. Always ask *which*.

**Thresholds / zones:** Typical annualized SD by category: liquid ~0.5–1, short-duration debt ~1–2, conservative hybrid ~4–6, aggressive hybrid ~9–12, large-cap ~12–15, flexi ~12–16, mid-cap ~15–18, small-cap ~17–25+. Per §5.7: weak if ≫ peers unpaid; acceptable if ≈ peers; strong if ≤ peers with ≥ peer returns.

**The trap:** Reading high SD as automatically bad, or comparing SD across categories (25 is alarming for large-cap, normal for small-cap).

**Strong answer mentions:**
- States SD is only meaningful within-category, vs category average
- Distinguishes "paid" SD (compensated by mean) from "unpaid" SD
- Reads a low-SD outlier in an aggressive category as a manager trait, not a defect
- Notices direction of change (rising/falling) and asks why
