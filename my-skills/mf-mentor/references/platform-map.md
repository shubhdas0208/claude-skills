# Platform Map — where every number lives, free

The user looks numbers up manually (no APIs, by design — the looking IS the learning). Send them to the cheapest-friction free source. Never send them to a paid tier; every metric below has a free path.

| Number needed | Free source | Where |
| --- | --- | --- |
| Trailing returns, ratios (Sharpe/Sortino/SD/beta/alpha), VR rating | Value Research | Fund page → Returns / Risk tabs; comparison tool |
| Category averages (SD, returns, ratios) | Value Research | Category page (e.g., "Equity: Flexi Cap") → category stats |
| Calendar-year returns (2020, 2022 stress years) | Value Research / Moneycontrol | Fund page → yearly/annual returns section |
| Screener + coarse filters (age, AUM, TER, rating) | Moneycontrol | MF screener; filters by category + Direct plan |
| Checklist pillars (Performance/Portfolio/Operations/Risk /25) | Moneycontrol | Fund page → Checklist tab — use weak pillars as investigation pointers |
| R-squared | Morningstar India | Fund page → Risk → MPT statistics |
| Rolling returns | **Advisorkhoj** (free) or Rupeevest | Rolling-return tool; avg, minimum, % windows beating benchmark |
| Portfolio overlap between two funds | **Advisorkhoj** (free) | "Portfolio Overlap" tool; bar < 33% |
| Cap split, top-10 weight, sector weights, cash % | VR/Morningstar fund page or AMC factsheet | Portfolio tab / monthly factsheet |
| YTM, modified duration, credit table (debt) | AMC monthly factsheet | AMC site → Downloads → Factsheet; also AMFI |
| TER (current, official) | AMC site / AMFI TER disclosure | AMC → TER page (apps can lag) |
| Manager name + "managing since" | VR fund page / factsheet | Fund page header |
| Exit load, riskometer | Fund page / factsheet | Header row |
| Benchmark TRI returns | Index factsheet (NSE/BSE) or VR fund page benchmark row | Always TRI, never PRI (§3.4) |
| Your own XIRR after buying | Groww / Kuvera / Coin / MFCentral | Portfolio view — do not rebuild this in the workspace |

Paywall workarounds: VR Premium rolling-return charts → Advisorkhoj/Rupeevest. Morningstar Premium x-ray → AMC factsheets + Advisorkhoj overlap. Never suggest anything paid.

When asking the user to fetch, give: source, exact page/tab, and what to read out — one fetch request at a time.
